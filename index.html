Penn State Roar Supercomputer Experimental Setup

1. Controlled Multi-turn Controller

Bounded 6-turn loop exercising local Qwen2.5-Coder models via Ollama. Intercepts bash execution, file writes, and code tests with zero unmonitored external calls.

2. Audit & Telemetry Validation

Verifies token arithmetic, prompt caching signatures, and process termination across Slurm node clusters. Preserves unsuccessful runs when telemetry is complete.

3. Conformal Upper Budgeting

Uses 450 official calibration task groups to compute empirical task-group residual scores, establishing rigorous capacity reservation ceilings.
